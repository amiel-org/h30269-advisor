## V3.2 规则

### 加仓链

1. 全收益口径（`H20269` vs `H00985`）消除5-7月分红除息假摔；5年Beta调整后40日全收益差进入低估区，且经 $R^2$ 稳健收缩后的2年、3年、5年窗口全部确认低估。
2. 股债利差有支撑（中性下限收紧至 `1.2%` 或 `1.8x`），且滚动 PE 历史分位 `< 80%`（极端强买 `≤ -8%` 除外），防止红利估值泡沫期高位追买。
3. 按策略资金池分档执行（买入 `12%` / 加仓 `16%` / 强买 `20%`，总仓重仓线 `80%`）；同向加仓建议间隔至少 `5` 个交易日，短期趋势只决定执行快慢。

### 减仓链

1. Beta调整后40日全收益差处于 `5%~7%` 时只暂停新增，不触发卖出。
2. 战术减仓必须**在同一收盘日同时满足**：2/3/5年窗口调整后差值均 `≥7%`、红利全收益40日涨幅 `≥5%`、全收益站上MA250，并连续 `2` 个已收盘交易日完整达标。
3. 盘中点位不计入连续收盘确认；此前正式收盘确认已完成且盘中条件仍满足时，可生成战术仓条件执行方案，收盘后独立复核。
4. 战术仓条件全部满足后，按策略资金池减战术仓 `10` 个百分点（以当前战术仓余额为上限），核心仓不动。
5. 核心仓降档复核额外满足：全收益高于MA250至少 `10%`、多条件过热连续 `5` 个收盘日、股债性价比转弱或滚动 PE 分位 `≥ 75%`；先减战术仓，不足部分可降核心仓，但保留至少 `45%` 底仓。

程序使用明确的 `action_code` 判断动作，不再根据中文结论里是否出现“减仓”二字猜测执行建议。

## 模型边界

1. 程序只生成规则化建议，不自动交易。
2. 原始相对收益差只用于观察轮动，不能直接触发卖出。
3. Beta是历史校正系数，不是固定真值，因此页面同时展示经 $R^2$ 稳健收缩后的2年、3年、5年结果；窗口分歧时动作降级为观察。
4. 短期趋势只控制分批速度，不单独改变买卖方向。
5. 数据源结构变化时程序会报错或阻断，不会伪造结果。

### 双资产总资金池配置层（`/portfolio`，v1.0）

- **核心动机**：沪深300（宽基进攻）与红利低波（价值压舱）在 2017-12-29 至 2026-10-13 共同样本期内独立仓位相关性仅 `0.141`（2022 前沪深300 占优、2022 后红利低波占优）。分开记账会长期闲置大量现金。
- **配置规则**：基础预算 50% / 50%；当一侧有闲置预算时，按 `50%` 补位系数乘以平滑 PE 估值衰减系数向另一侧释放额度（沪深300 上限 `65%`，红利低波上限 `70%`，总权益硬封顶 `90%`，现金底线 `≥10%`），配合 `5%` 再平衡死区、单步最多 `10` 个百分点、同向冷却 `5` 个交易日及**防误杀保护**（估值温和上升时只暂停继续补位，不强制砍掉已有持仓）。
- **同口径实证回测**（2017-12-29 至 2026-10-13，均含 1.8% 现金收益、扣 0.20% ETF 年化费率与 5bp 佣金）：
  - 统一总池 `v1.0`（初始 50% 红利底仓）：年化 **9.28%**，最大回撤 **-14.81%**，超额夏普 **0.678**，卡玛比率 **0.63**（同期分池独立 50/50 年化 8.37%、夏普 0.649、卡玛 0.57；2022 前后两段均跑赢分池 50/50）。
  - 统一总池 `v1.0`（初始 0% 纯现金起步）：年化 **9.51%**，最大回撤 **-13.99%**，超额夏普 **0.727**，卡玛比率 **0.68**（同期分池独立 50/50 年化 8.75%、最大回撤 -13.63%、超额夏普 0.714、卡玛 0.64）。

### 沪深300 盘中决策台（服务 v2.9.0，收盘模型 v2.5）

- 指标：中证官方滚动PE，`ERP = 100/PE - 10年国债`（越高越便宜）
- 分位：全历史扩展 + 近10年/近5年滚动三窗口，最少700个观测，**不含当日**；单窗口PE阶梯与ERP闸门均带 **±2.0分位点对称回滞缓冲**，显著抑制分位边界震荡期的反复买卖
- 目标仓位：PE阶梯与ERP闸门取小，向下取整到 12.5% 网格
- 执行：每次仅动 1 格，买 1 日确认 / 卖 2 日确认，死区 5%，收盘出信号**次日收盘成交**
- 仓位口径：**策略专用预算**的比例，不是家庭总资产比例；三窗口分歧时保持现仓，若真实仓位超出全部窗口区间会给出越界风险提示
- 冻结快照回测（2014-08-22 至 2026-10-13，样本内）：真实资金池核算（含闲置现金年化 1.8%、扣除 ETF 年化费率 0.20%、单边佣金 5bp）年化 **9.80%**，最大回撤 **-22.50%**，超额夏普 **0.738**，调仓 **79** 次（零现金同口径下年化由 v2.4 的 8.05% 提升至 **8.70%**，夏普由 0.739 提升至 **0.801**，2016年震荡期拉锯交易减少 58%）。线上最新收盘结果会随数据更新。
- 同期满仓持有年化7.33%、最大回撤-46.0589%。页面主区用最新报价即时计算PE、ERP、三窗口目标与观察线；已发布收盘留作对照及原策略确认。盘中方案没有独立盘中回测，不能引用原收盘回测作为盘中交易业绩。
- 长假（春节/国庆）后首交易日若已取得当日实时报价，盘中终端自动桥接节前基准日线，不再误报过期停摆。
- 参数经同一样本比较选择，没有干净样本外验证或经核实的实盘业绩，不能称为“实战打赢”。费用假设和局限见页面及 `hs300/HS300_审计与修复_2026-10-15.md`。

### 页面与仓位试算说明

- 与红利低波保持同一终端布局：真实000300日K、MA20/60/250、3月/6月/1年、十字光标、缩放与拖动；分时源可用时显示真实分时。缺OHLC的历史点只显示收盘线，不伪造蜡烛。
- 当日最后一根K线来自真实报价和高低点，标明动态；不写入正式日线，不增加收盘确认次数。
- 默认30秒自动检查，页面隐藏时暂停，手动可刷新；正常报价源为中证指数，缺失或明显延迟时尝试腾讯备用。缓存读取时也重新计算报价年龄。
- 实际仓位仅存本机浏览器，不自动下单、不读取券商账户、不保存实际成交。调整幅度是一次试算，多次刷新不意味着可以反复执行。
- 金额基于资金池当前总市值，暂未扣手续费或按ETF交易单位取整，不是可直接提交的订单。金额和仓位只保存在本地浏览器。
