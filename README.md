# H30269 & HS300 双决策台

程序自动抓取 `H30269`、中证全指 `000985`、红利低波股息率和中国10年国债收益率，以5年滚动Beta校正40日相对收益，并用2年、3年、5年窗口检查结论稳健性。

## Cloudflare 云端版（推荐）

仓库包含 Cloudflare Worker 云端实现：Worker 负责抓取公开金融数据、执行与本地版一致的 V3.1 规则，并托管原有网页静态资源。云端版支持手工刷新、最近历史记录和交易日收盘后定时刷新。

直接打开：<https://h30269-hs300.anyongliang027.workers.dev>

云端版不需要在本机启动 Python。工作日北京时间 15:10 自动刷新，也可以在网页右上角手工刷新。

```powershell
npm install
npm run test:cloudflare
npm run deploy:cloudflare
```

Cloudflare 使用 `wrangler.jsonc`，静态资源由 `npm run build:cloudflare` 生成到忽略版本管理的 `cloudflare-dist\`。Python 本地版继续保留，作为离线备用和规则对照基线。

## V3.1 规则

### 加仓链

1. 5年Beta调整后40日差进入低估区，且2年、3年、5年窗口结论一致。
2. 股债利差仍有支撑。
3. 按计划仓位分批执行；短期趋势只决定执行快慢，不单独决定买入。

### 减仓链

1. Beta调整后40日差处于 `5%~7%` 时只暂停新增，不触发卖出。
2. 战术减仓必须同时满足：2/3/5年窗口调整后差值均 `≥7%`、红利自身40日收益 `≥5%`、站上MA250、连续 `2` 个已收盘交易日确认。
3. 盘中点位不计入连续收盘确认；此前正式收盘确认已完成且盘中条件仍满足时，可生成战术仓条件执行方案，收盘后独立复核。
4. 战术仓条件全部满足后默认只减持仓约 `5%`，核心仓不动。
5. 核心仓降档还要额外满足：高于MA250至少 `10%`、相对过热连续 `5` 个收盘日、股债性价比降至中性或弱支撑。

程序使用明确的 `action_code` 判断动作，不再根据中文结论里是否出现“减仓”二字猜测执行建议。

## 命令行版

双击 `run_advisor.bat`，或在 PowerShell 中运行：

```powershell
python .\advisor.py
```

每次运行会生成：

- `latest.md`：最新中文报告
- `latest.json`：最新结构化结果
- `reports\`：历史报告
- `cache\`：行情缓存，在线接口短时失败时备用

## 数据源

- 指数历史行情、当天点位：中证指数有限公司公开接口
- 红利低波股息率：蛋卷基金公开指数估值接口
- 中国10年国债收益率：中国债券信息网

程序记录每项数据的来源和日期。行情过旧时会输出“暂停行动”，不会静默拿旧数据给出买卖建议。

## 常用参数

```powershell

# 只使用缓存
python .\advisor.py --offline

# 只使用正式日线，不合并盘中点位
python .\advisor.py --no-intraday

# 临时覆盖股息率或国债收益率
python .\advisor.py --dividend-yield 5.2 --bond-yield 1.75
```

## 模型边界

1. 程序只生成规则化建议，不自动交易。
2. 原始相对收益差只用于观察轮动，不能直接触发卖出。
3. Beta是历史校正系数，不是固定真值，因此页面同时展示2年、3年、5年结果；窗口分歧时动作降级为观察。
4. 短期趋势只控制分批速度，不单独改变买卖方向。
5. 数据源结构变化时程序会报错或降级，不会伪造结果。

### 沪深300 盘中决策台（服务 v2.5，原研究规则 v2.4）

- 指标：中证官方滚动PE，`ERP = 100/PE - 10年国债`（越高越便宜）
- 分位：扩展窗口，最少700个观测，**不含当日**
- 目标仓位：PE阶梯与ERP闸门取小，向下取整到 12.5% 网格
- 执行：每次仅动 1 格，买 1 日确认 / 卖 2 日确认，死区 5%，收盘出信号**次日收盘成交**
- 仓位口径：**策略专用预算**的比例，不是家庭总资产比例
- 冻结快照回测（2014-08-22 至 2026-10-13，样本内）：年化 8.0484%，最大回撤 -22.4081%，夏普 0.7386，调仓91次，平均仓位约41.2%。线上最新收盘结果会随数据更新。
- 同期满仓持有年化7.33%、最大回撤-46.0589%。固定初始41.2%预算比较年化3.73%、最大回撤-28.29%；该比例来自事后平均仓位，并非波动率匹配。
- 页面主区用最新报价即时计算PE、ERP、三窗口目标与观察线；已发布收盘留作对照及原策略确认。填入策略资金池的实际仓位后计算增减方向和最多12.5个百分点的一档试算。盘中方案没有独立盘中回测，不能引用原收盘回测作为盘中交易业绩。
- 当前观察线与当前估值共用相同历史池，排除当日临时观察；PE按报价比例估算，盈利、成分及国债变更后须更新。报价时间和源明确可见，超过3分钟的交易时报价标为延迟并停止给可执行比例。
- 参数经同一样本比较选择，没有干净样本外验证或经核实的实盘业绩，不能称为“实战打赢”。费用假设和局限见页面及 `hs300/HS300_审计与修复_2026-10-15.md`。
- Windows 本地双页面请用 `npm run dev:cloudflare`；`run_webapp.bat` 的 Python 服务仍仅支持红利低波。
- 服务补丁 v2.4.1：保留验证过的历史，收盘后仅补最近两周行情与国债第1页；待发布、源超时、数据过期分别提示，保留注明日期的历史分析。浏览器对临时网络/5xx失败自动重读一次；这不改变v2.4模型参数。

### v2.5 页面与数据

- 与红利低波保持同一终端布局：真实000300日K、MA20/60/250、3月/6月/1年、十字光标、缩放与拖动；分时源可用时显示真实分时。缺OHLC的历史点只显示收盘线，不伪造蜡烛。
- 当日最后一根K线来自真实报价和高低点，标明动态；不写入正式日线，不增加收盘确认次数。
- 默认30秒自动检查，页面隐藏时暂停，手动可刷新；正常报价源为中证指数，缺失或明显延迟时尝试腾讯备用。缓存读取时也重新计算报价年龄。
- 实际仓位仅存本机浏览器，不自动下单、不读取券商账户、不保存实际成交。调整幅度是一次试算，多次刷新不意味着可以反复执行。
- 盘中规则复用已有估值与风险阶梯，交易时点改变后的真实业绩未验证。历史样本收益仍只对应原收盘研究。

### v2.5.1：看懂窗口与仓位试算

- “近10年”比较最近2440条日线（约10年），不是持有年限。页面同时显示实际历史起止日、样本数、PE历史位置、股债利差历史位置和单窗口参考仓位。
- ERP这里指 `100/PE - 10年期国债收益率` 的代理指标；历史位置是排名，不是收益率、胜率或股息率。点击解释可查看公式，点击“这个仓位怎么算”可查看PE上限与ERP闸门。
- 仓位输入后不再因休市或窗口分歧提前结束计算。填写仓位百分比、可选资金池金额后，点击“测算我的仓位”查看持仓/现金、整体结果、三个单独窗口情景。输入变动即时重算，金额不填也能比较比例。
- 三窗口分歧时，整体结果明确保持现仓、调整0元；情景表仅说明“假如只按一个窗口”，不取平均、不合并执行，不改变原共识规则。休市/延迟行情也可计算，但会标注仅试算。
- 金额基于资金池当前总市值，暂未扣手续费或按ETF交易单位取整，不是可直接提交的订单。金额和仓位只保存在本地浏览器。
